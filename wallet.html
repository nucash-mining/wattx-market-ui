1satBazaar is a self-custody ordinals and UTXO wallet for WATTx, Bitcoin, Litecoin, Bitnet and Bitcoin SV. Hold coins, view your 1Sat ordinals, inscribe, and connect to WATTx dApps — with keys that are generated and stored only in your own browser.

Chrome — in review Edge — in review Firefox — in review Download .zip

Brave users: install from the Chrome Web Store — Brave serves Chrome extensions directly. Until the store listings are approved, use the .zip and load it unpacked (steps below).

Multi-chain

Switch between WATTx, Bitcoin, Litecoin, Bitnet and BSV from the header. Each chain shows only the address types it actually supports, and reads from its own indexer.

Ordinals

View 1Sat Ordinals and WATTx inscriptions in a built-in gallery, and inscribe on WATTx directly from the wallet.

Collectibles protected

On BSV, ordinals sit in tiny outputs beside ordinary coins. 1satBazaar pins them out of coin selection — and refuses to build a transaction if it can't check.

dApp ready

Provides window.wattx so WATTx dApps — the Marketplace, Binary Maker and the 100K Club — can request signatures. Every transaction needs your approval.

Install from .zip

Download and unzip 1satbazaar-chromium-*.zip (or the Firefox build).
Open brave://extensions, chrome://extensions or edge://extensions and turn on Developer mode.
Click Load unpacked and select the unzipped folder. On Firefox, use about:debugging → Load Temporary Add-on.
Open the wallet, create or import a seed phrase, and write the 12 words down offline.

Self-custody, no telemetry

Keys are generated in your browser and stored in extension storage. There is no account, no server holding your coins, and no analytics of any kind. The wallet talks only to public blockchain indexers to read balances and broadcast the transactions you approve. Privacy policy →
